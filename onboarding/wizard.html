Set up your agent

Five steps, about 15 minutes. Each one is checked as you go.

1Claude login

Already set. Paste a new token below only to replace it.

  1. In the terminal on your server (or any computer with Claude Code), run claude setup-token.
  2. Open the link it shows, log in with your Claude account (Pro or Max), and paste the code back there.
  3. It prints a token starting with sk-ant-oat. Paste it here.

2Telegram

Already set. Paste a new bot token below only to replace it.

On Telegram, open @BotFather, send /newbot, and pick a name and a username. It replies with a token.

Now open on Telegram and send it any message, like “hi”. Then press:

3Your timezone

For reminders like “at 6pm”. We guessed it from your browser.

4Private access (Tailscale)

Already set. Paste a new key below only to replace it.

Your agent's pages open only on your own devices, through Tailscale.

  1. Sign up at tailscale.com, and install Tailscale on your phone and laptop.
  2. On the DNS page, turn on MagicDNS and HTTPS Certificates.
  3. On the Keys page, click Generate auth key (the defaults are fine) and paste it here.

5GitHub backups (optional)

Connected.

  1. Create two empty private repos (no README): agent-workspace for the agent's files, and agent-history for your conversations.
  2. Create a private GitHub App for your agent. When GitHub asks which repos it may use, pick Only select repositories and those two.

Steps 1 to 4 are needed. You can come back for GitHub later.
